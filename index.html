One-time setup

Connect a free Firebase database to go live

Right now this file has no database connected, so students on their own phones or laptops can't join. Takes about 5 minutes, completely free at classroom scale:

  1. Go to console.firebase.google.com and create a new project (name it anything, e.g. "showtime-game").
  2. In the left sidebar under Build, click Realtime Database → Create Database → choose a location → start in test mode.
  3. Click the ⚙️ gear icon → Project settings, scroll to "Your apps", click the </> (Web) icon, and register an app (no need for Firebase Hosting).
  4. Copy the firebaseConfig object shown on screen.
  5. Open this HTML file in a text editor, find const firebaseConfig = { near the top of the script, and paste your values in place of the placeholders.
  6. Save the file and reload this page (or re-upload it wherever you're hosting it).

This screen disappears automatically once a valid config is detected. See the reply in chat for a suggested database security rule to paste in as well.
